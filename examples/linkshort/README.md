# Example: linkshort

What `docs/spec/` looks like part-way through a small project: a URL shortener, two of four tasks done. It is here to show the shape of the files, so the source code is not included and the numbers are illustrative.

Things to notice:

- [SPEC.md](docs/spec/SPEC.md) states the core model in one sentence, with the date the user confirmed it, and records a spike's result instead of its code.
- [modules/store.md](docs/spec/modules/store.md) lists invariants, not only signatures, and names what the module must never depend on.
- Each file in [tasks/](docs/spec/tasks/) has one acceptance check you can observe. [Task 2](docs/spec/tasks/002.md) failed once; its Attempts section says what the second attempt changed.
- [TASKS.md](docs/spec/TASKS.md) is generated by `git bpm index`. The STOP row before task 4 is the user's: the run halts there until they clear it.
- [baseline.txt](docs/spec/baseline.txt) carries a rule per metric. `p95_ms 12 max+25%` means a review fails if the p95 goes above 15 ms.
- [HANDOFF.md](docs/spec/HANDOFF.md) is enough to resume from in a fresh session.
