## Task
`POST /links` accepts an optional `ttl` in seconds. `GET /<code>` for an expired link answers `410` and does not redirect. Expired links stay in the store.

## Acceptance check
Create a link with `ttl: 1`, wait 2 s, then `curl -i localhost:8000/<code>` answers `410`. A link created without a ttl in the same run still answers `302`.
